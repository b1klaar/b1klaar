# B1Klaar

Oefenmateriaal voor inburgering en staatsexamen NT2. Nederlands leren
met feiten die kloppen: elke bewering op de site is gecheckt tegen de
officiële bronnen (DUO, staatsexamensnt2.nl, inburgeren.nl, e-ANS).

- **Gratis tool: [De of het?](https://b1klaar.github.io/de-of-het/)** —
  lidwoord-trainer, 291 woorden, elk antwoord met de regel erbij. Direct
  in de browser of offline in één HTML-bestand
  ([broncode](https://github.com/b1klaar/de-of-het)).
- **Site: [b1klaar.hmdev.nl](https://b1klaar.hmdev.nl/)** — uitleg per
  examenonderdeel, gratis oefenpagina's voor lezen, luisteren, schrijven,
  spreken, KNM en grammatica, in vier talen.
- **Anki-decks met audio** voor de hele B1-route:
  [store](https://klaarify3.gumroad.com/). Gratis samples en
  oefentoetsen beschikbaar.
- **Nieuwsbrief: [b1klaar.substack.com](https://b1klaar.substack.com/)** —
  wekelijkse uitleg over het examen, met bronvermelding.

Free Dutch exam-prep material (inburgering / staatsexamen NT2) by
B1Klaar. Start with the free de/het trainer above.
